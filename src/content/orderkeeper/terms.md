**OrderKeeper（单掌柜）**
生效日期：2026-11-20

## 1. 服务说明

单掌柜是一款运行在 iPhone 上的本地记账、出库单与月度对账工具。所有业务数据保存在本机，我们不提供云同步、服务器存储或远程账户。

## 2. 免费版与 Pro 订阅

- **免费版**：每个自然月可新建 20 张订单；查看、编辑已有数据、备份与恢复始终免费。
- **Pro 订阅**：无限新建订单、对账单 PDF/CSV 导出、分享到微信、出库单分享与打印。
  - 月付：¥10 / 月
  - 年付：¥100 / 年
  - 价格以 App Store 购买确认页显示的为准。
- 订阅通过 Apple App Store 自动续期，可在 iOS「设置 → Apple 账户 → 订阅」中取消。取消后当前订阅周期结束前仍可使用 Pro 功能。

## 3. 优惠码

优惠码通过 Apple 的 Offer Code / Promo Code 机制兑换，每个码的使用限制由 Apple 与发行方设定。我们不运营独立的优惠码服务器。

## 4. 退款

退款由 Apple 按其退款政策处理。请通过 Apple 的「报告问题」页面申请。

- 本 App 不提供税务、会计或法律意见；对账结果仅供经营参考，请自行核对。
